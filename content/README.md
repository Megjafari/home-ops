# Content

Blog posts, one folder per post, written in Markdown with Mermaid diagrams.

```text
content/posts/<slug>/
├── post.md          # the text
└── ...              # images and diagram sources used by the post
```

The posts are copied here from the old blog database as they were. Wiring the
blog to read them at build time is the next step; until then the live blog
still serves its own content.
